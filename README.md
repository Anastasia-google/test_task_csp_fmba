# Docker-образ с инструментами для анализа секвенирования (samtools, bcftools, vcftools)

Данный репозиторий содержит `Dockerfile` для сборки образа на базе Ubuntu 22.04, включающего специализированные биоинформатические программы и библиотеки.

## Состав образа

В образе установлены следующие специализированные программы и библиотеки (все версии зафиксированы):

| Программа / Библиотека | Версия | Путь установки (внутри контейнера) |
| :--- | :--- | :--- |
| **libdeflate** | 1.26 | `/soft/libdeflate-1.26` |
| **HTSlib** | 1.24 | `/soft/htslib-1.24` |
| **SAMtools** | 1.24 | `/soft/samtools-1.24` |
| **BCFtools** | 1.24 | `/soft/bcftools-1.24` |
| **VCFtools** | 0.1.17 | `/soft/vcftools-0.1.17` |
| **pysam** *(после выполнения 3 задания)* | 0.24.1 | системный Python 3 (через `pip3`) |

Все исполняемые файлы доступны через переменную `$PATH`. Также созданы отдельные переменные окружения: `$SAMTOOLS`, `$BCFTOOLS`, `$VCFTOOLS`.
*(после выполнения 3 задания)* Дополнительно в образ скопирован скрипт `add_ref_allele.py` (в `/usr/local/bin/add_ref_allele.py`), описанный в `FP_SNPs_README.md`.

## Клонирование репозитория

Для сброки и запуска данного docker-файла необходимо клонировать этот репозиторий и переместиться в директорию, которая появится при клонировании репозитория и
где содержится docker-файл.
```bash
git clone https://github.com/Anastasssikk/test_task_cspfmba.git
cd test_task_cspfmba/
```

## Сборка Docker-образа

Для сборки образа необходимо выполнить следующую команду в терминале (находясь в корневой директории репозитория, где лежит `Dockerfile`):

```bash
docker build -t bio-tools:latest .
```
## Запуск контейнера

Для запуска контейнера в интерактивном режиме необходимо выполнить следующую команду.

```bash
docker run -it --rm bio-tools:latest
```
